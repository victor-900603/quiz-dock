# JSON 匯入格式

QuizDock 以單一 JSON 檔匯入題庫。檔案可直接上傳或貼上內容，匯入前會先驗證並顯示題數、主題分布與前幾題預覽。

## 檔案限制

| 項目 | 限制 |
| --- | --- |
| 檔案大小 | 10MB |
| 題數 | 5000 題 |
| 每題選項數 | 2 至 10 個 |
| 題幹長度 | 20000 字元 |
| 解析長度 | 20000 字元 |

## 最外層結構

支援兩種寫法。

### 信封格式

```json
{
  "title": "生物學第一章",
  "description": "細胞與遺傳",
  "topic_labels": {
    "1": "細胞構造",
    "2": "遺傳學"
  },
  "questions": []
}
```

| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `title` | 字串 | 否 | 題庫標題。空白時改用檔名，仍為空則為「未命名題庫」 |
| `description` | 字串 | 否 | 題庫說明，空白時不儲存 |
| `topic_labels` | 物件 | 否 | 主題代碼對應顯示名稱，值可為字串或數字 |
| `questions` | 陣列 | 是 | 題目陣列，不可為空 |

### 純陣列格式

```json
[
  {
    "question": "題目內容",
    "options": { "A": "選項甲", "B": "選項乙" },
    "correct_answers": ["A"]
  }
]
```

純陣列沒有題庫層級欄位，標題取檔名（副檔名會移除）。匯入對話框中的「題庫標題」若有填寫，一律優先於 JSON 內的標題與檔名。

## 題目欄位

| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `question_number` | 數字或數字字串 | 否 | 題號，也是更新題庫時辨識題目的依據。省略時依檔案順序編號（1 開始） |
| `topic` | 字串或數字 | 否 | 主題代碼，會轉為字串 |
| `question` | 字串 | 是 | 題幹，不可空白 |
| `options` | 物件或陣列 | 是 | 選項，至少 2 個、最多 10 個 |
| `correct_answers` | 字串或字串陣列 | 是 | 正確答案，至少 1 個，且必須存在於選項 |
| `explanation` | 字串 | 否 | 解析，空白時不儲存 |

### 選項

物件格式以鍵為選項代碼：

```json
"options": {
  "A": "細胞核",
  "B": "粒線體"
}
```

陣列格式適合需要固定順序或鍵含特殊字元的情況：

```json
"options": [
  { "key": "A", "text": "細胞核" },
  { "key": "B", "text": "粒線體" }
]
```

正規化規則：

- 選項鍵會去除前後空白並轉為大寫。
- 選項依鍵以數字感知排序，例如 `A1`、`A2`、`A10`。
- 選項鍵重複或空白會產生錯誤。

### 正確答案

可寫成單一字串或字串陣列：

```json
"correct_answers": ["A", "B"]
```

- 答案會去除前後空白、轉為大寫、去重並排序。
- 答案不存在於選項時會產生錯誤。
- 多選題直接列出多個答案。

## 重複與題號

`question_number` 是題目的身分。更新題庫時，相同題號視為同一題，因此不要任意重新編號。

| 情況 | 結果 |
| --- | --- |
| 同題號且內容完全相同 | 視為重複列，只保留第一筆 |
| 同題號但內容不同 | 錯誤 `DUPLICATE_QUESTION_NUMBER` |
| 不同題號但內容完全相同 | 錯誤 `DUPLICATE_QUESTION` |

內容比較範圍為題幹、正規化後的選項與正確答案，不含解析與主題。

## 錯誤碼

| 錯誤碼 | 意義 |
| --- | --- |
| `INVALID_JSON` | 檔案不是有效 JSON |
| `INVALID_SHAPE` | 最外層不是陣列，也不是含 `questions` 陣列的信封物件 |
| `EMPTY_QUESTIONS` | `questions` 為空陣列 |
| `INVALID_QUESTION` | 題目不是物件、缺少題幹、題幹空白或過長、解析格式錯誤 |
| `INVALID_OPTIONS` | 選項格式錯誤、少於 2 個、超過 10 個、鍵空白或重複 |
| `INVALID_CORRECT_ANSWERS` | 答案格式錯誤、沒有答案，或答案不在選項中 |
| `FILE_TOO_LARGE` | 檔案超過 10MB |
| `TOO_MANY_QUESTIONS` | 題數超過 5000 題 |
| `DUPLICATE_SOURCE` | 同一份內容已匯入過 |
| `DUPLICATE_QUESTION_NUMBER` | 同題號出現不同內容 |
| `DUPLICATE_QUESTION` | 不同題號出現相同內容 |
| `IMPORT_FAILED` | 寫入資料庫失敗 |

驗證錯誤會一次列出多筆問題，畫面最多顯示 20 筆。

## 完整範例

```json
{
  "title": "生物學第一章",
  "description": "細胞構造與遺傳入門",
  "topic_labels": {
    "1": "細胞構造",
    "2": "遺傳學"
  },
  "questions": [
    {
      "question_number": 1,
      "topic": "1",
      "question": "下列哪一個胞器負責產生 ATP？",
      "options": {
        "A": "細胞核",
        "B": "粒線體",
        "C": "高基氏體"
      },
      "correct_answers": ["B"],
      "explanation": "粒線體是細胞進行有氧呼吸與產生 ATP 的主要場所。"
    },
    {
      "question_number": 2,
      "topic": "2",
      "question": "DNA 的鹼基配對中，腺嘌呤（A）會與哪一個鹼基配對？",
      "options": [
        { "key": "A", "text": "胸腺嘧啶（T）" },
        { "key": "B", "text": "鳥嘌呤（G）" },
        { "key": "C", "text": "胞嘧啶（C）" }
      ],
      "correct_answers": ["A"]
    }
  ]
}
```

## 匯出與更新

題庫詳情頁的「匯出 JSON」會輸出與匯入相同的信封格式，可直接作為匯入或更新來源。匯出時：

- 選項與正確答案已依相同規則排序。
- `description` 與 `topic_labels` 為空時會省略。
- 沒有解析的題目保留 `explanation: null`。

「更新題庫」以題號比對新舊內容：

- 題號相同且內容未變：保留題目與作答進度。
- 題號相同但內容變更：更新題目，並重新計算該題既有作答紀錄的正確性。
- 新題號：附加在練習順序最後。
- 未出現的題號：刪除題目，並連帶刪除相關作答與標記，無法復原。
- 題庫標題不會因更新而改變；重新命名請使用「重新命名」。

更新前會顯示差異與受影響的作答、標記數量，確認後才寫入。更新流程不是單一交易，若中途失敗，以同一份檔案重試即可收斂；已寫入的題目與進度會依題號重新對齊。
