# 匯入格式

QuizDock 支援 JSON、CSV 與 TSV。檔案可直接上傳、拖曳或貼上內容，匯入前會先驗證並顯示題數、主題分布與前幾題預覽；格式有誤時會直接列出問題，不會只顯示模糊的失敗訊息。匯入對話框右上角的問號按鈕會開啟說明視窗，內含各格式範例、欄位別名、答案寫法與常見錯誤。

## 檔案限制

| 項目 | 限制 |
| --- | --- |
| 檔案大小 | 10MB |
| 題數 | 5000 題 |
| 每題選項數 | 2 至 10 個 |
| 題幹長度 | 20000 字元 |
| 解析長度 | 20000 字元 |

## JSON

### 最外層結構

支援純陣列，也支援帶中繼資料的信封物件。題目陣列可放在下列任一欄位：

- `questions`
- `data`
- `items`
- `list`

也接受再包一層的寫法，例如 `{ "quiz": { "questions": [...] } }` 或 `{ "result": { "data": [...] } }`。

信封物件的中繼資料：

| 欄位 | 別名 | 型別 | 說明 |
| --- | --- | --- | --- |
| `title` | `name` | 字串 | 題庫標題；空白時改用檔名，仍為空則為「未命名題庫」 |
| `description` | `desc` | 字串 | 題庫說明，空白時不儲存 |
| `topic_labels` | `topicLabels`、`topics` | 物件 | 主題代碼對應顯示名稱，值可為字串或數字 |

純陣列沒有題庫層級欄位，標題取檔名（副檔名會移除）。匯入對話框中的「題庫標題」若有填寫，一律優先於 JSON 內的標題與檔名。

JSON 檔若帶 UTF-8 BOM，會自動去除後再解析。

### 題目欄位

| 欄位 | 別名 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- | --- |
| `question` | `stem`、`prompt`、`content`、`text` | 字串 | 是 | 題幹，不可空白 |
| `options` | `choices` | 物件或陣列 | 是 | 選項，至少 2 個、最多 10 個 |
| `correct_answers` | `correctAnswers`、`correct_answer`、`answer`、`correct` | 字串、數字、陣列或物件 | 是 | 正確答案，至少 1 個 |
| `question_number` | `questionNumber`、`number`、`no` | 數字或數字字串 | 否 | 題號，也是更新題庫時辨識題目的依據；省略時依檔案順序編號（1 開始） |
| `topic` | `subject`、`category` | 字串或數字 | 否 | 主題代碼，會轉為字串 |
| `explanation` | `rationale`、`analysis` | 字串 | 否 | 解析，空白時不儲存 |

題號若明確提供但無法解析為正整數，會產生錯誤，不會默默改用檔案順序，以免更新題庫時對錯題目身分。

### 選項

下列寫法都可以：

```json
"options": { "A": "細胞核", "B": "粒線體" }
```

```json
"options": [
  { "key": "A", "text": "細胞核" },
  { "key": "B", "text": "粒線體" }
]
```

```json
"options": ["細胞核", "粒線體", "高基氏體"]
```

純字串陣列會自動配 `A`、`B`、`C`。若需要固定順序或鍵含特殊字元，使用 `{ key, text }` 陣列。

也可以把正確答案標在選項上，此時可省略 `correct_answers`：

```json
"options": [
  { "text": "細胞核", "correct": false },
  { "text": "粒線體", "correct": true }
]
```

物件格式的值也可以是 `{ "text": "粒線體", "correct": true }`。

正規化規則：

- 選項鍵會去除前後空白並轉為大寫。
- 選項依鍵以數字感知排序，例如 `A1`、`A2`、`A10`。
- 選項鍵重複或空白會產生錯誤。
- 陣列中的空選項會在 CSV 匯入時略過，並重新依序配鍵。

### 正確答案

可接受的寫法：

```json
"correct_answers": ["A", "B"]
```

```json
"correct_answers": "A"
```

```json
"correct_answers": "粒線體"
```

```json
"correct_answers": 2
```

```json
"correct_answers": { "A": true, "B": false, "C": true }
```

```json
"correct_answers": "A、C"
```

解讀規則：

- 字串會先比對選項鍵，再比對選項文字。
- 數字會先比對同名選項鍵（例如選項鍵為 `1`、`2`），找不到才視為第幾個選項（從 1 開始）。
- 多個答案可用逗號、頓號、分號或空白分隔；`AB` 這種連寫在每個字元都是有效選項鍵時也會拆分。
- 陣列格式直接列出多個答案。
- 布林對應表會取值為 `true` 的鍵。
- 答案會去除前後空白、轉為大寫、去重並排序。
- 答案不存在於選項時會產生錯誤。

## CSV 與 TSV

CSV 與 TSV 適合從 Excel、Google Sheets 匯出。第一列通常是標題，匯入時會自動判斷分隔符與常見欄位名稱，也可以在「欄位對應」區手動調整。

### 編碼

- UTF-8（含 BOM）優先。
- 若內容不是有效的 UTF-8，會嘗試以 Big5 解碼。
- 仍無法辨識時請將檔案另存為 UTF-8。

### 欄位對應

匯入對話框提供以下設定：

- 第一列是標題：取消勾選時，第一列會被視為資料。
- 題幹欄位：必選。
- 答案欄位：必選，內容可為選項鍵、選項文字或數字。
- 題號、主題、解析欄位：選填。
- 選項欄位：可勾選多個，依勾選的欄位順序配 `A`、`B`、`C`。

系統會依標題自動猜測，例如 `題幹`、`題目`、`question`、`stem`、`選項A`、`答案`、`解析`、`主題`、`題號`。猜錯時直接改選即可。

### 範例

```csv
題號,題幹,選項A,選項B,選項C,答案,解析,主題
1,下列哪一個胞器負責產生 ATP？,細胞核,粒線體,高基氏體,B,粒線體是產生 ATP 的主要場所。,細胞構造
2,DNA 的腺嘌呤會與哪一個鹼基配對？,胸腺嘧啶,鳥嘌呤,胞嘧啶,A,,遺傳學
```

對應結果與 JSON 匯入相同，會先經過相同的驗證、去重與題號規則。

## 重複與題號

`question_number` 是題目的身分。更新題庫時，相同題號視為同一題，因此不要任意重新編號。

| 情況 | 結果 |
| --- | --- |
| 同題號且內容完全相同 | 視為重複列，只保留第一筆 |
| 同題號但內容不同 | 錯誤 `DUPLICATE_QUESTION_NUMBER` |
| 不同題號但內容完全相同 | 錯誤 `DUPLICATE_QUESTION` |

內容比較範圍為題幹、正規化後的選項與正確答案，不含解析與主題。

## 錯誤碼

| 錯誤碼 | 意義 |
| --- | --- |
| `INVALID_JSON` | 檔案不是有效 JSON |
| `INVALID_SHAPE` | 最外層不是陣列，也不是含題目陣列的物件 |
| `EMPTY_QUESTIONS` | 題目陣列為空 |
| `INVALID_QUESTION` | 題目不是物件、缺少題幹、題幹空白或過長、解析格式錯誤、題號不是正整數 |
| `INVALID_OPTIONS` | 選項格式錯誤、少於 2 個、超過 10 個、鍵空白或重複 |
| `INVALID_CORRECT_ANSWERS` | 答案格式錯誤、沒有答案，或答案不在選項中 |
| `FILE_TOO_LARGE` | 檔案超過 10MB |
| `TOO_MANY_QUESTIONS` | 題數超過 5000 題 |
| `DUPLICATE_SOURCE` | 同一份內容已匯入過 |
| `DUPLICATE_QUESTION_NUMBER` | 同題號出現不同內容 |
| `DUPLICATE_QUESTION` | 不同題號出現相同內容 |
| `IMPORT_FAILED` | 寫入資料庫失敗 |

驗證錯誤會一次列出多筆問題，畫面最多顯示 20 筆。

## 完整範例

```json
{
  "title": "生物學第一章",
  "description": "細胞構造與遺傳入門",
  "topic_labels": {
    "1": "細胞構造",
    "2": "遺傳學"
  },
  "questions": [
    {
      "question_number": 1,
      "topic": "1",
      "question": "下列哪一個胞器負責產生 ATP？",
      "options": {
        "A": "細胞核",
        "B": "粒線體",
        "C": "高基氏體"
      },
      "correct_answers": ["B"],
      "explanation": "粒線體是細胞進行有氧呼吸與產生 ATP 的主要場所。"
    },
    {
      "question_number": 2,
      "topic": "2",
      "question": "DNA 的鹼基配對中，腺嘌呤（A）會與哪一個鹼基配對？",
      "options": ["胸腺嘧啶（T）", "鳥嘌呤（G）", "胞嘧啶（C）"],
      "correct_answers": "A"
    }
  ]
}
```

## 匯出與更新

題庫詳情頁的「匯出 JSON」會輸出與匯入相同的信封格式，可直接作為匯入或更新來源。匯出時：

- 選項與正確答案已依相同規則排序。
- `description` 與 `topic_labels` 為空時會省略。
- 沒有解析的題目保留 `explanation: null`。

「更新題庫」以題號比對新舊內容：

- 題號相同且內容未變：保留題目與作答進度。
- 題號相同但內容變更：更新題目，並重新計算該題既有作答紀錄的正確性。
- 新題號：附加在練習順序最後。
- 未出現的題號：刪除題目，並連帶刪除相關作答與標記，無法復原。
- 題庫標題不會因更新而改變；重新命名請使用「重新命名」。

更新前會顯示差異與受影響的作答、標記數量，確認後才寫入。更新流程不是單一交易，若中途失敗，以同一份檔案重試即可收斂；已寫入的題目與進度會依題號重新對齊。
